# Poke Battle Arena This is a single-file browser game. It pulls every Pokémon and move from the [PokeAPI](https://pokeapi.co), so you can pick any of the 1,025 Pokémon species for your team. Each Pokémon gets real moves like Thunderbolt, Flamethrower, or Hydro Pump, and battles use type matchups, STAB, and speed-based turn order. ## How to run it 1. Copy the code below into a file named `index.html`. 2. Open it in any modern browser. An internet connection is required. ## The code ```html Poke Battle Arena

⚡ Poke Battle Arena ⚡

1. Build your team of 6 (any Pokémon!)

Your Team

Battle Log

``` ## Features - **Choose any Pokémon:** all 1,025 species are searchable by name or National Dex number. - **Team of 6:** build your team, remove members, and start when you have six. - **Cartoon-style attacks:** each Pokémon gets 4 real attacking moves (such as Thunderbolt, Earthquake, or Hydro Pump), each with a type, power, accuracy, and description on hover. - **Battle system:** type effectiveness ("super effective" / "not very effective" / "no effect"), same-type attack bonus (STAB), speed-based turn order, accuracy checks, and random damage variance. - **Switching:** swap Pokémon during battle, and pick a replacement when yours faints. - **CPU opponent:** the foe gets a random team of six and usually uses its strongest move. ## Ideas to extend it - Let players choose moves from each Pokémon's full move list instead of random picks. - Add status moves (burn, paralysis, sleep) and stat boosts. - Add a Random Team button or a "Team Preview" screen. - Add cartoon-style sound effects or animations for each attack.
